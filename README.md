# Student Management System

A Spring Boot REST API application for managing student records.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Oracle Database
- Maven
- Postman

## Features

- Add Student
- Get Student By Id
- Get All Students
- Update Student
- Delete Student
- Search Student By Name
- Partial Name Search
- Global Exception Handling

## API Endpoints

POST /students

GET /students

GET /students/{id}

PUT /students/{id}

DELETE /students/{id}

GET /students/name/{name}

GET /students/search/{name}
